تقرير بحثي: دور لغة التنسيق (CSS) في صفحات الويب

اسم الطالبة: سارة أمين أمين

الرقم الجامعي: 2500376

المقدمة

تعتبر لغة CSS هي الأساس في إعطاء الجمالية لأي موقع إنترنت.

عرض الموضوع

بينما تهتم لغة HTML بالهيكل الأساسي للصفحة، تأتي CSS لتضيف اللمسات الفنية. وفي عالم تصميم وتطوير مواقع الويب حالياً لا تقتصر إنشاء المواقع الإلكترونية على كتابة النصوص وإضافة صور فقط، بل يكون الموقع في حاجة لتصميم جذاب ومنظم يجعل المنظر مريحاً للعين ويستمتع المستخدم بتصفحه ويساعد في الوصول إلى المعلومات بسهولة، وهذا هو دور CSS الذي يعد من أهم التقنيات المستخدمة في تصميم صفحات الويب وتنسيقها.
